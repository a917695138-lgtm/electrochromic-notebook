# [含光谱电化学数据] 2026-09-08 四款电解液及加EMIM版本响应时间筛选

同一天做了**两组**光谱电化学测试，差别在**基线处理方式**：空气基线（0FTO）与 1FTO 基线校正。
两组共用同一批电极体系与同一套电解液体系，合并记录以便交叉比对。

> 命名口径：**1FTO / 0FTO** 指光谱是否用 1 片 FTO 校正基线；**1ATO / 2ATO** 指对电极 ATO 层数，
> 两者是不同变量，不可混淆。

## 器件与测试条件（两组共用）

| 项目 | 内容 |
|------|------|
| 器件结构 | FTO / 介孔 TiO₂–PBI-Cl / 电解质 / ATO / FTO |
| 工作电极 | 介孔 TiO₂–PBI-Cl（旧批次） |
| 电解质 | LiClO4、LITFSI-ACN、S50、KLDTF33-EMIMTFSI、LITFSI-ACN-EMIMTFSI、S50-EMIMTFSI |
| 电解质浓度 | 锂盐统一 1 mol/L（1×10⁻³ mol/mL）；含 EMIMTFSI 版本摩尔比 锂盐:EMIMTFSI = 1:2 |
| 电位程序 | −1.8→0 V、−2→−1 V（空气基线组另有 −2.2→0 V） |
| 步时 | 3 s |
| 响应定义 | t90（90% ΔT），波长取各样品 max 对比度波长 |

未记录项：隔层规格、封装方式、S50 配方说明。

## 关键结论

- **响应最快**：KLDTF33-EMIMTFSI −2-1（3S），着色 0.54 s / 褪色 0.20 s，ΔT 57.8%；重复样 0.75 / 0.18 s，重复性可接受。
- **综合最优候选**：LiClO4 −2-1（3S），0.94 / 0.58 s，ΔT 55.7%，两端较均衡，不依赖极端电位。
- **加入 EMIMTFSI 未普遍提速**：LITFSI-ACN 加 EMIMTFSI 后着色由 0.81 s 变为 1.86–1.89 s；S50 加 EMIMTFSI 后重复样出现 ΔT 8.8% / 13.7% 的低值。
- **S50-EMIMTFSI 组内离散极大**（8.8% ~ 56.7%），该组合成膜/浸润状态不稳定。

## 异常

- `S50 −1.8-0（3S）-2` 最大对比度波长落在 764.1 nm，远离主峰区（~640 nm），疑长波噪声误判为响应峰，该条不宜直接引用。
- `S50-EMIMTFSI −1.8-0（3S）`（ΔT 8.8%）与 `−2-1（3S）`（ΔT 13.7%）远低于同组水平，需回溯原始 .nox 确认是否漏液/接触不良。
- `LITFSI-ACN −2-1（3S）` 两次重复着色 0.81 s 与 0.15 s、ΔT 47.3% 与 27.6%，离散显著，单条数据代表性有限。

# 三、两组交叉对比

- **对比度整体抬升**：同体系在 1FTO 基线下 ΔT 普遍由 45–57% 抬到 55–68%。
  LiClO4 −2-1 由 55.7% → 63.9%，S50 −2-1 由 57.8% → 64–68%。
  **跨批次比较必须固定基线方式**，否则 ΔT 不可比。
- **注意变量混杂**：1FTO 组里的 LITFSI-ACN 与 LITFSI-ACN-EMIMTFSI 两组同时改用了 **1ATO 对电极**，
  与空气基线组之间的差异包含"基线 + 对电极层数"两个变量，不能单独归因于基线。
- **S50 + EMIMTFSI 的稳定性问题在两组数据中重复出现**（空气基线 8.8% / 13.7%，1FTO 33.8% / 41.8%）。

# 下一步

- S50 与 S50-EMIMTFSI 组补充重复样，确认低 ΔT 是否为器件制备问题。
- 后续实验统一记录基线方式（0FTO / 1FTO）与对电极层数（1ATO / 2ATO），避免变量混杂。
- 主攻体系取舍须在同一种基线方式下重测。
- 补记隔层规格、封装方式与 S50 配方。
