# [含光谱电化学数据] 2026-09-14 120 μm 沙林膜与 100 μm 双面胶隔层对比及 CV 预处理影响

## 测试体系与数据来源

比较 120 μm 沙林膜与 100 μm 双面胶两种隔层构造下的响应时间与对比度，并考察 CV 预处理（文件名标 `after cv`，即先跑 CV 程序再测响应时间）的影响。本批次统一采用 **0FTO（空气基线）**。

原始数据位于 `D:\Desktop\光谱电化学\ASL\20260914 120um沙林膜及100um双面胶\20260914 120um沙林膜及100um双面胶`。汇总表为 `20260914 120um沙林膜及100um双面胶响应时间汇总.xlsx`（18 条记录，4 个体系分组）。

## 器件与测试条件

| 项目 | 内容 |
|------|------|
| 器件结构 | FTO / 介孔 TiO₂–PBI-Cl / 电解质 / ATO / FTO |
| 电解质 | KLDTF33-EMIMTFSI、LITFSI-ACN、LITFSI-ACN-EMIM，锂盐统一 1 mol/L；含 EMIM 版本摩尔比 锂盐:EMIMTFSI = 1:2 |
| 隔层 | 120 μm 沙林膜 / 100 μm 双面胶；文件名中"120um"与"120shalin"均指 **120 μm 沙林膜**（同一膜种） |
| 电位程序 | −1.8→0 V、−2→−1 V |
| 步时 | 3 s |
| 预处理 | 部分样品先跑 CV 再测响应时间（标 after cv；after cv -1times 表示 CV 扫 1 圈） |
| 基线 | 0FTO（空气基线） |

## 关键结论

- **隔层效应**：同为 LITFSI-ACN −1.8-0（3S），100 μm 双面胶为 1.25 / 1.98 s（ΔT 52.5%），120 μm 组为 0.17 / 1.06 s（ΔT 43.6%）。隔层变化影响明显，但 120 μm 组对比度反而更低，**不能只看厚度，膜种与压合状态同样关键**。
- **CV 预处理效果依赖体系**：KLDTF33-EMIMTFSI 在 −2-1 由 1.58 / 0.09 s（ΔT 53.9%）变为 0.56 / 0.12 s（ΔT 57.6%），着色显著加快；LITFSI-ACN-EMIM 上变化很小（0.32/1.36 → 0.31/1.20 s）。
- **本组最优**：LITFSI-ACN-EMIM 120 μm 沙林膜 −2-1（3S）after cv-2，0.31 s / 0.73 s，ΔT 59.8%。
- **KLDTF33-EMIMTFSI 褪色极快但着色慢**：−2-1 褪色 0.09 s 而着色 1.58 s，两端极不平衡。

## 异常

- `LITFSI-ACN-EMIM −2-1（3S）after cv-2`（604.7 nm）与 `LITFSI-ACN −2-1（3S）after cv -1times`（601.6 nm）波长明显低于同组，波长判定存疑。
- **同体系隔层效应（2026-10-21 修正口径）**：同为 LITFSI-ACN（无 EMIM），100 μm 双面胶 ΔT 为 52.5 / 52.7 / 57.2%，120 μm 沙林膜为 42.4 / 42.4 / 43.3 / 43.4 / 43.6 / 44.8%，**相差 9–13 个百分点**——这才是真正的隔层效应，且方向与"越厚对比度越低"的直觉一致。
- **此前"13 个百分点"的比较不成立，已更正**：旧表述把"120um 命名组（43–45%）"与"120shalin 命名组（51–58%）"当作同一体系比较，实际两者**电解质不同**——"120um"命名组为 **LITFSI-ACN（无 EMIM）**；"120shalin"命名组为 **KLDTF33-EMIMTFSI 与 LITFSI-ACN-EMIM（均含 EMIM）**。膜种同为 120 μm 沙林膜，故该差异主要来自电解质体系，不归因于封装压力或器件个体差异。
- 数据版本说明：本批汇总于 2026-10-19 重跑（`summarize_response_time.py` 分类规则修正后），18 条全部归入 4 个体系；工具侧的处理过程记录在 `notes/2026-10-19-naming-convention-and-cross-batch-summary.md`，不在本实验记录中重复。
