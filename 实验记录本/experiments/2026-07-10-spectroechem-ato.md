# [含光谱电化学数据] 7.4旋涂样品xuantu2响应时间测试与ATO制备记录

## 实验目的

记录 7.4 制备的旋涂样品后续光谱电化学测试结果，并补充 ATO 1 层 / 2 层与清洗基底准备情况。2026-07-13 对 xuantu2 系列响应时间数据按 90% 阈值两点线性插值法重新整理。

## 一、ATO 制备与基底准备

| 项目 | 说明 |
|---|---|
| ATO 层数 | 1 层 / 2 层 |
| 基底 | 清洗 FTO 片 |
| 基底类型 | 打孔 / 无孔 |

## 二、光谱电化学响应时间数据汇总与分析（线性插值重算）

**数据状态：已整理。** 本记录关联 2026-07-10 批次 `CA_PBI-Cl_1ATO_new LiClO4-xuantu2` 系列光谱电化学/CA 响应时间测试数据；结构化 JSON 已同步到 `data/2026-07-10-xuantu2-spectroechem-response-time.json`。

### 处理方法

响应时间采用实测 90% 阈值与两点线性插值法。综合响应时间按所有有效循环的稳定性计算，本批 4 组样品均采用有效循环均值±标准差作为代表统计。

### 关键结论

- **最高对比度**：S03 (`-2 / 0 V`) 与 S04 (`-2 / 0.5 V`) 并列，最大对比度均为 **44.4191%**。
- **最快着色**：S03，`t_c = 0.6540 s`。
- **最快褪色**：S04，`t_b = 0.2989 s`。
- 电压窗口从 `-1.5 / 0 V` 增强到 `-2 / 0 V` 后，着色响应明显加快，同时对比度提高；继续到 `-2 / 0.5 V` 主要改善褪色速度。

### 结果分析

1. `-2 / 0 V` 与 `-2 / 0.5 V` 给出本批最高对比度，说明更负的着色电位有助于提高光学调制幅度。
2. `-2 / 0 V` 的着色速度最快且综合响应较均衡，可作为后续快速响应与对比度折中的重点窗口。
3. `-2 / 0.5 V` 褪色最快，但着色慢于 `-2 / 0 V`；若后续目标是快速恢复透明态，可重点复测该窗口。
4. 本批整体最大对比度约 42.7-44.4%，低于 2026-07-04 批次单层 ATO 高对比度条件，后续需结合旋涂层厚度、染料负载和电极面积差异解释。
