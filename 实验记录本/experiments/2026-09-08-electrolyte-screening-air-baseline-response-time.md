# [含光谱电化学数据] 2026-09-08 四款电解液及加EMIM版本响应时间筛选（空气基线）

## 测试体系与数据来源

在 PBI-Cl / 2ATO(NEW) 两电极器件上比较四款基础电解质及其添加 EMIMTFSI 后的体系，筛选后续主攻电解液。本组光谱测试采用**空气基线（0FTO，不用 FTO 校正）**；同日的另一组采用 1FTO 基线，见 `2026-09-08-electrolyte-screening-1fto-baseline-response-time.md`。

原始数据位于 `D:\Desktop\光谱电化学\ASL\20260908 四款电解液及加EMIM的响应时间测试\20260908a`。汇总表为该文件夹下的 `20260908 四款电解液及加EMIM的响应时间测试响应时间汇总.xlsx`（18 条记录，6 个体系分组），另有 A4 打印版。汇总由响应时间 skill 生成，取值循环按"循环 2–10 内首个两端均不显著偏离均值±1 样本标准差的循环"规则自动选定。

## 关键结论

- **响应最快**：KLDTF33-EMIMTFSI −2-1（3S），着色 0.54 s / 褪色 0.20 s，ΔT 57.8%；重复样 0.75 / 0.18 s，重复性可接受。
- **综合最优候选**：LiClO4 −2-1（3S），0.94 / 0.58 s，ΔT 55.7%，两端较均衡，不依赖极端电位。
- **加入 EMIMTFSI 未普遍提速**：LITFSI-ACN 加 EMIMTFSI 后着色由 0.81 s 变为 1.86–1.89 s；S50 加 EMIMTFSI 后重复样出现 ΔT 8.8% / 13.7% 的低值。
- **S50-EMIMTFSI 组内离散极大**（8.8% ~ 56.7%），该组合成膜/浸润状态不稳定。

## 异常

- `S50 −1.8-0（3S）-2` 最大对比度波长落在 764.1 nm，远离主峰区（~640 nm），疑长波噪声误判为响应峰，该条不宜直接引用。
- `S50-EMIMTFSI −1.8-0（3S）`（ΔT 8.8%）与 `−2-1（3S）`（ΔT 13.7%）远低于同组水平，需回溯原始 .nox 确认是否漏液/接触不良。
- `LITFSI-ACN −2-1（3S）` 两次重复着色 0.81 s 与 0.15 s、ΔT 47.3% 与 27.6%，离散显著，单条数据代表性有限。

## 下一步

- S50 与 S50-EMIMTFSI 组补充重复样，确认低 ΔT 是否为器件制备问题。
- 与 1FTO 基线组交叉比对，评估基线处理对 ΔT 的影响幅度。
- 补记隔层规格、封装方式与 S50 配方。
