# 测试方法：EIS（电化学阻抗谱）

## 目的

测定电解质体系（如 DALE 系列）与器件的**离子电导、界面阻抗与电荷转移阻力**，
通过等效电路拟合分离体相电阻与界面贡献，用于解释离子传输与界面稳定性差异。

## 适用范围

- 固态 / 准固态电解质（DALE、DA 体系等）的离子电导与界面阻抗
- 完整器件的阻抗谱（变色层 / 电解质 / ATO 各界面贡献）

## 数据分析要点

1. **先看 Nyquist 图谱形**：高频区的截距对应体相/电解质电阻，中频半圆对应界面电荷转移，
   低频斜线对应离子扩散（Warburg）。
2. **选等效电路**：按谱形选择 R(RC)、R(RC)(RC) 或带 Warburg 元件的电路，
   避免为了拟合度堆砌元件。
3. **换算离子电导**：由拟合得到的体相电阻 R 结合样品厚度与面积换算 σ = L / (R·A)。
4. **温度依赖**：若做了变温测试，用 Arrhenius 关系处理，得到活化能。

## 注意事项

- 测试前确认器件/样品几何参数（厚度 L、有效面积 A），否则无法换算电导率。
- 扰动振幅不宜过大，避免非线性响应；固态体系界面阻抗大，低频段需足够采集时间。
- 与 Raman（LiTFSI 解离程度）、XRD（结晶性）结果交叉印证，
  避免把阻抗变化单独归因于某一因素。
