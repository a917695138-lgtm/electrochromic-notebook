# 旋涂样品台阶仪厚度与PBI-Cl染料配制记录

## 一、旋涂样品台阶仪厚度数据

测试对象为 2026-07-04 制备的旋涂样品，单位为 nm。

### 1. 测试数据

| 样品编号 | 层数 | 厚度数据（nm） |
|----------|------|----------------|
| 23 | 单层 | 171.12, 161.48 |
| 27 | 单层 | 116.868, 292.382 |
| 22 | 双层 | 786.81, 1089.63 |
| 29 | 双层 | 834.01, 820.791 |
| 75 | 三层 | 1027.12, 1211.058 |
| 30 | 三层 | 1368.59, 1079.9 |

### 2. 数据整理

- 单层样品厚度整体低于双层和三层样品。
- 双层与三层样品厚度明显增加，符合层数增加的趋势。
- 样品 27 和 30 的点位差异相对较大，后续可增加测试点复核均匀性。

## 二、PBI-Cl 染料配制实验（DMF 溶剂）

### 1. 理论配方参数

| 项目 | 数值 |
|------|------|
| 染料名称 | PBI-Cl |
| 摩尔质量 M | 856.35 g/mol |
| 目标浓度 C | 1 × 10^-3 mol/L |
| 目标物质的量 n | 5 × 10^-6 mol |
| 理论质量 m | 4.28175 mg |
| 溶剂 | DMF |

### 2. 实际操作数据

| 项目 | 数值 |
|------|------|
| 实际称量 | 4.71 mg |
| 定容体积 | 5.5 mL |

### 3. 实际浓度计算

```text
n实 = m实 / M
    = 4.71 × 10^-3 g / 856.35 g/mol
    ≈ 5.50 × 10^-6 mol

C实 = n实 / V
    = 5.50 × 10^-6 mol / 5.5 × 10^-3 L
    ≈ 1.00 × 10^-3 mol/L
```

### 4. 结果

- 实际浓度与目标浓度吻合。
- 可用于后续染浴上述旋涂器件。

## 结论与下一步

- 旋涂样品厚度随层数增加而增大，适合后续和器件性能联动分析。
- PBI-Cl 染料配制浓度满足目标要求，可继续用于后续染浴实验。
