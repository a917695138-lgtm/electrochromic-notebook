判定表面 SEI 层的**存在性、化学组成与深度梯度**，用于解释循环衰减机制。

## 结果

**未处理。** 原始谱尚未做荷电校正、背底扣除与分峰拟合，暂不给成分结论。

### 待核对的判读靶点（依据 2026-10-21 文献调研）

| 物种 | 谱区 | 结合能 / eV |
|---|---|---|
| LiF | F 1s | 685.0 / 685.3 |
| LiF | Li 1s | 55.6 |
| Li₃N | N 1s | 398.7 / 399.3 |
| Li₃N | Li 1s | 55.1 |
| C–F（TFSI⁻） | F 1s | 688.6 |
| C–F（TFSI⁻） | C 1s | 292.8 |

判断逻辑：若溅射后 685 eV（LiF）相对 688.6 eV（C–F）显著增强，说明 TFSI⁻ 在界面发生分解并
生成富 LiF 的 SEI；若 688.6 eV 始终占主导且随深度不衰减，则更可能是**冲洗残留**而非 SEI。

## 下一步建议

1. **先做荷电校正再分峰**：原始谱以动能记录且样品导电性差，先统一校正到结合能轴（C–C 284.8 eV）再分峰；
   深度方向只比较相对变化，不做 nm 深度标定。
2. **分峰顺序**：先 C 1s 定荷电校正量 → F 1s 定 LiF/C–F 比例 → Li 1s、N 1s 交叉验证 Li₃N 与 LiF。
3. **四样品横向对比**：DALE50 vs DALE00（EMIMTFSI 的影响）、DALE50 vs DAE50（LiTFSI 的影响）、
   DALE50 vs CF DALE50（原位 vs 非原位固定），把成分差异与各自的循环衰减行为对起来。
4. 若外层含 Li 物种信号受空气暴露干扰严重，下次制样改用手套箱冲洗 + 真空转移。
