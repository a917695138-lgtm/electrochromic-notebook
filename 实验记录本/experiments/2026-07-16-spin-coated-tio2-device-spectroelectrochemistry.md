# [含光谱电化学数据] 2026-07-16 旋涂 TiO₂ 器件封装与光谱电化学测试

## 测试体系与数据来源

对**旋涂法制备的 TiO₂ 层**器件进行封装并做光谱电化学测试，此处以**两层旋涂（xuantu2）**的样品为例。

原始命名规律：`CA_PBI-Cl_1ATO_new LiClO4-xuantu2-{电位}（{步长}）`

| 项目 | 内容 |
|---|---|
| 器件结构 | FTO / 旋涂 TiO₂–PBI-Cl / 电解质 / ATO / FTO |
| 变色层 | **两层旋涂 TiO₂**（xuantu2），区别于刮涂工艺 |
| 对电极 | **1ATO（单层 ATO）** |
| 电解质 | LiClO4 |
| 步时 | 5 s |
| 循环数 | 10 |
| 电位条件 | 1.5-0、1.8-0.2、2-0、2-0.5（单位 V） |

峰值波长集中在 **593–595 nm**，组内漂移小于 2 nm，波长一致性好。

## 关键结论

- **对比度整体偏低**：4 组 ΔT 仅 42.7–44.4%，明显低于同期刮涂体系与 9–10 月批次（55–68%）。
- **最快褪色**：1.8-0.2（5S），τb = 0.4486 s。
- **最快着色 + 最高对比度**：2-0（5S），τc = 0.9142 s，ΔT 44.42%。
- **Tmax 都在 80% 以上**（80.7–81.8%），说明褪色态透过率正常，低对比度主要来自 **Tmin 偏高（37–38%）**——
  即着色不够深，而不是褪色态退化。

### 对比度偏低的原因（推测，待验证）

旋涂 TiO₂ 层厚度显著小于刮涂层，可供 PBI-Cl 锚定的比表面积与总吸附量不足，
导致着色态吸光度上不去。属合理推断，**需膜厚与染料吸附量数据佐证**。
