# 测试方法：EIS 电化学阻抗谱测试与分析流程

Autolab · NOVA 2.1｜含关键截图 · 操作单

## 目的与适用范围

测定电解质体系（如 DALE 系列）与器件的**离子电导、界面阻抗与电荷转移阻力**，通过等效电路拟合分离体相电阻与界面贡献，用于解释离子传输与界面稳定性差异。适用于固态 / 准固态电解质（DALE、DA 体系等）的离子电导与界面阻抗，以及完整器件的阻抗谱（变色层 / 电解质 / ATO 各界面贡献）。

## 总体流程

准备程序 → 测 OCP 并链接偏压 → 设置 FRA → 查看 Nyquist/Bode → Window 选点 → 半圆估计初值 → 编辑电路 → 迭代拟合 → 核对参数与保存。

| 环节 | 视频时间 | 要完成的动作 |
|---|---|---|
| 程序与数据 | 00:16–01:04 | Open library；找到原始数据与 FRA 模板 |
| OCP 与偏压 | 01:08–02:50 | 添加 OCP；链接到 Apply 的 Potential |
| 测试参数 | 02:54–03:54 | 频率范围、点密度、扰动振幅 |
| 选点与图层 | 04:04–05:38 | Windower；保留原图，另建 5 号图 |
| 半圆与初值 | 05:40–06:44 | Electrochemical circle fit；Copy 描述 |
| 电路模型 | 06:46–08:20 | 依据曲线特征编辑等效电路 |
| 迭代拟合 | 08:22–09:58 | F5；固定/释放 Rs、Rp；F9 |
| 结果解释 | 10:00–13:04 | 读 Rs、Rp；限定比较条件与适用范围 |

使用重点：视频示例是三电极超电体系，展示"小半圆＋低频尾部"的拟合操作。等效电路和示例数值都不能直接当作待测样品的结论。

## 1 建立程序，测 OCP 并链接直流偏压

视频位置：00:16–02:50。打开 Open library，找到数据；在 Default procedures → Impedance spectroscopy 中选择 FRA impedance potentiostatic。此模板需要仪器具备相应 FRA 功能。

将 OCP 命令放在 Apply potential 前。示例程序顺序为 Autolab control → OCP → Apply → Cell on → Wait 5 s → FRA measurement → Cell off。

按 Ctrl 选中需要链接的命令，点击工具栏的链条图标进入 Edit links，将 OCP value 连接到 Apply 的 Potential。

**图 1｜01:35  链接 OCP value → Apply 的 Potential；这里传递的是测得的 OCP，而非一直使用固定的 0 V。**

![图 1](assets/eis-flow-01.png)

检查 OCP 的时间上限和 dE/dt 稳定判据。视频示例最多测量 60 s；作者强调可延长至 120 s 等，而达到时间上限不等于电位已稳定。

**图 2｜02:26  OCP 属性与程序顺序；示例测得 0.12576 V，Apply 随链接采用相同数值。**

![图 2](assets/eis-flow-02.png)

分析补充：EIS 应在相对稳定的工作点下进行。若 OCP 仍持续漂移，应延长平衡并检查体系；Wait 5 s 只是视频设置，不能代替稳定性确认。研究指定着色/漂白电位时，使用目标偏压并待状态稳定，而不是机械套用 OCP。

## 2 设置 FRA 测试参数

视频位置：02:54–03:54。选中 FRA measurement，在右侧 Properties 检查频率、步进方式和振幅。

**图 3｜03:38  FRA measurement 的完整参数区；界面为 100 kHz → 0.1 Hz，振幅显示 0.01 V RMS。**

![图 3](assets/eis-flow-03.png)

| 字段 | 视频画面/讲解 | 实际使用时的核对 |
|---|---|---|
| First applied frequency | 1E+05 Hz | 高频端为 100 kHz |
| Last applied frequency | 画面 0.1 Hz；口述可至 0.01 Hz | 是否充分覆盖慢过程；低频耗时更长 |
| Frequency step type | Points per decade | 按对数频率布点 |
| Number of frequencies | 10 per decade | 每个十倍频程 10 点 |
| Amplitude | 0.01 V RMS = 10 mV RMS | 同时记录单位与 RMS/峰值定义 |
| Wave type | Sine | 正弦扰动 |

口述示例：作者常用 0.01–10⁵ Hz，较简单体系可止于 0.1 Hz，并估计更低频测试约需 20 分钟。实际时长取决于频率下限、积分/周期数、仪器设置及稳定性，不能照搬这个时间。

分析补充：振幅用于在直流偏压附近施加小信号。以界面数值和单位为准，不混用 V、mV、峰值和 RMS。可用较小振幅复测验证线性；若阻抗随振幅明显变化，应调整测试条件。

## 3 查看曲线，选择拟合数据并保留原图

视频位置：04:04–05:38。视频结果区包含 Nyquist、Bode 以及 OCP 等图；Nyquist 横轴为 Z′，纵轴为 −Z″，坐标单位均为 Ω。

选中 FRA measurement，点击扳手图标并添加 Windower。进入 Boundaries 选择数据点；数据有效时优先使用完整范围。

**图 4｜04:42  Windower → Boundaries：选择参与后续处理的点。剔除点时记录频率、原因和范围。**

![图 4](assets/eis-flow-04.png)

检查极低频抖动、明显异常点及横轴下方的高频响应。不要仅因数据"不好看"就删除；应先检查漂移、接线和重复性。

进入 Windower 的 Plots，启用 Nyquist 并将 Plot number 指向新图层。视频建立 5 号图，以避免修改原始图。后续拟合输出也使用该图层。

**图 5｜05:28  Plots 中的 Plot number 字段：示例随后改为 5；编号只是本次演示的图层标识。**

![图 5](assets/eis-flow-05.png)

分析补充：按图上纵轴 −Z″ 判断符号。若曲线在横轴下方，则 −Z″＜0、Z″＞0，属于感性响应的候选特征；不能简单说成"原始虚部为负就是电感"。还需排查电缆及仪器寄生效应。

## 4 用半圆估计初值，建立拟合命令

视频位置：05:40–06:44。在 Windower 后分别添加 Electrochemical circle fit 和 Fit and simulation。前者估计半圆与初始参数，后者执行完整电路的非线性拟合。

进入 Electrochemical circle fit，放大高频半圆区域，选择能够代表弧线的数据点。半圆不完整或与扩散重叠时，初值的可信度会下降。

**图 6｜06:15  半圆选择结果及右侧 Copy 按钮；图中 Rs、Rp 等为初始估计，不是最终报告值。**

![图 6](assets/eis-flow-06.png)

点击 Copy。返回 Fit and simulation，将复制的信息粘贴到 Circuit description；该字段为空时不能直接开展拟合。

**图 7｜06:30  Circuit description 字段与 Edit 按钮；填入描述后再编辑模型。**

![图 7](assets/eis-flow-07.png)

将拟合/模拟曲线的输出目标设置为前一步建立的 5 号图，使原始数据与拟合结果能够叠加比较。

分析补充：圆拟合只是求初值的工具。视频演示选点较随意；正式分析需确保选点覆盖真实半圆，避免把低频尾部当作半圆。初值应结合高频截距、弧宽和材料/界面过程判断。

## 5 按物理过程编辑等效电路

视频位置：06:46–08:20。仅用半圆初始电路时曲线明显不匹配；作者在 Equivalent Circuit Editor 中加入 W、L 和 C。视频最终示例拓扑为：

`L — Rs — [(Rp — W) ∥ CPE] — C`

NOVA 示例 Circuit description：`[LR([RW]Q)C]`；其中 Q 为 CPE。

**图 8｜08:14  视频示例电路：L、Rs 串联；Rp 与 W 串联后和 CPE 并联；末端再串联 C。**

![图 8](assets/eis-flow-08.png)

| 元件 | 规范化理解（分析补充） |
|---|---|
| Rs | 串联欧姆电阻，可包含电解液、引线及接触等贡献；不宜全部称为接触电阻。 |
| Rp / Rct | 本示例对应界面电荷转移电阻；是否可称 Rct 取决于模型与体系。 |
| CPE（Q） | 常相位元件，描述非理想电容响应；参数为 Y₀、n，不能直接把 Y₀ 当电容。 |
| W | Warburg 元件，用于描述相应扩散过程；具体形式需与扩散边界相符。 |
| L / C | 分别描述模型中的感性、容性过程；应有实验和物理依据再加入。 |

分析补充：CPE 不是"扩散元件"的同义词。低频尾部不为 45°，也不能仅凭外观就添加电容"校正角度"；有限扩散、孔隙/分布效应和漂移等都可能改变形状。选择能解释主要过程的最简模型，避免堆叠元件。

## 6 初次拟合与固定/释放参数

视频位置：08:22–09:58。在电路编辑器中使用 F5（Run Fit and Simulation）首次拟合，检查曲线与右侧 Results。视频先出现 Convergence No，说明即便 χ²看似不大，也不能认为拟合成功。

| 动作 | 视频中的处理顺序 |
|---|---|
| 先检查 | 核对 Rs、Rp 初值及量级；明显异常值需处理 |
| 临时固定 | 选择 Rs、Rp 元件，在属性中勾选 Fixed |
| 继续拟合 | F9：Resume Fit and Simulation，先优化其余参数 |
| 释放参数 | 取消 Rs、Rp 的 Fixed，再按 F9 继续拟合 |
| 复查结果 | 检查叠加曲线、Convergence、χ²及参数合理性 |

**图 9｜09:08  选择 Rp 后显示参数属性及 Fixed；视频同时固定 Rs、Rp。此操作是改善初值/收敛的技巧。**

![图 9](assets/eis-flow-09.png)

分析补充：最终若保留固定参数，应报告固定值及依据。不能因为固定后"有了半圆"就接受结果；还要解除不必要的固定并复核。F9 改善结果不代表所选电路具有唯一性。

## 7 检查拟合质量，再解释 Rs 与 Rct

视频位置：09:44–13:04。视频在解除固定并继续拟合后，拟合线与数据点的对应关系改善，最终 Results 显示 Convergence Yes。

**图 10｜09:48  拟合曲线与数据点叠加；同时检查小半圆、低频尾部和高频段，不只看整体外观。**

![图 10](assets/eis-flow-10.png)

**图 11｜10:14  最终电路参数局部：示例 Rs≈1.13 Ω，Rp≈1.48 Ω；仅为视频示例值。**

![图 11](assets/eis-flow-11.png)

核对 Convergence、残差随频率是否存在系统偏差、χ²和参数量级。χ²受权重与算法定义影响，不设跨软件通用的单一合格阈值。

读取并报告 Rs、Rp/Rct、CPE 的 Y₀与 n，以及模型中其余元件；同时保留单位、拟合频率范围、约束与权重设置。

在相同电极配置、面积、电解液、温度和偏压/状态下比较样品。Rct 下降通常支持界面电荷转移改善，不能单独证明体相导电性提高。

用于电致变色样品的分析补充：分别在规定的着色/漂白电位与稳定状态下测量，记录预处理、保持时间、面积及循环次数。OCP 条件与偏压条件分开解释；两个半圆或分布特征明显时，应重新选择模型。

## 8 保存结果与打印记录单

归档补充：视频没有演示完整导出步骤。为使结果可复核，保存 NOVA 原始数据与处理命令；另存原始频率–Z′–Z″数据、拟合曲线、等效电路和参数表。根据当前 NOVA 版本使用对应保存/导出入口。

报告图至少包含：Nyquist 实验点＋拟合线、Bode 模值/相位、拟合电路；补充残差图或其他有效性检验（如 Kramers–Kronig）可提高可信度。

记录所有剔除点、固定参数、权重和拟合区间；保留未处理原始数据。比较样品时统一坐标和测试条件，避免只报告一个 Rct 数字。

## 数据分析要点（本项目）

1. **先看 Nyquist 图谱形**：高频区的截距对应体相/电解质电阻，中频半圆对应界面电荷转移，低频斜线对应离子扩散（Warburg）。
2. **选等效电路**：按谱形选择 R(RC)、R(RC)(RC) 或带 Warburg 元件的电路，避免为了拟合度堆砌元件。
3. **换算离子电导**：由拟合得到的体相电阻 R 结合样品厚度与面积换算 σ = L / (R·A)。
4. **温度依赖**：若做了变温测试，用 Arrhenius 关系处理，得到活化能。

## 注意事项

- 测试前确认器件/样品几何参数（厚度 L、有效面积 A），否则无法换算电导率。
- 扰动振幅不宜过大，避免非线性响应；固态体系界面阻抗大，低频段需足够采集时间。
- 与 Raman（LiTFSI 解离程度）、XRD（结晶性）结果交叉印证，避免把阻抗变化单独归因于某一因素。
